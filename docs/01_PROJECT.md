# Deskripsi Project

SMKN11 Landing Page merupakan website profil sekolah berbasis Laravel yang bertujuan untuk memberikan informasi mengenai SMK Negeri 11 kepada masyarakat secara online.

Website terdiri dari dua bagian utama:

- **Frontend** (Landing Page) untuk pengunjung.
- **Backend** (Admin Panel) menggunakan Sneat Bootstrap Admin untuk mengelola seluruh konten website.

---

# Tujuan Project

Project ini dibuat untuk:

- Menampilkan informasi sekolah.
- Menampilkan profil sekolah.
- Menampilkan jurusan.
- Menampilkan berita.
- Menampilkan galeri kegiatan.
- Menampilkan informasi kontak.
- Mempermudah administrator dalam mengelola seluruh data website.
